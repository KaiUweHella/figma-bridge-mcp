# Own Variable code syntax mutation

`var code-syntax` uses one closed Variable Code Syntax Command Application from
Commander and `figma_run`. Its authentic Command Plan is a
confirmation-configured, non-retrying Figma write with one target and decreasing
deadline. Neither Adapter owns Plugin code, rollback or output formatting.

The request validates bounded Variable, optional Collection and literal syntax
payloads before readiness. It canonicalizes WEB, ANDROID and iOS and requires
exactly one syntax value or explicit `--remove`. Variable resolution retains id,
exact-name, path-tail and unique partial-name utility; every ambiguity fails
before mutation.

The Plugin validates complete Variable Facts before the first write, snapshots
whether the platform already has a syntax and its previous value, then invokes
one official setter or remover. Complete post-write Facts and the affected
platform postcondition are validated inside the guarded mutation phase. A later
failure restores an overwritten or removed syntax with the setter, or removes a
newly added syntax. Restore failure returns one bounded residue identity. No
dispatched mutation retries.

Variable Code Syntax and Variable Mode Value Mutation share one generated local
Variable resolution and Plugin-side Facts-validation runtime. Successful output
retains the established complete Variable Facts JSON. Variable metadata, values,
Collection metadata and token import remain separate Commands.
