# Own Variable Collection extension

`col extend` uses one closed Collection Extension Command Application from
Commander and `figma_run`. Its authentic Command Plan is a
confirmation-configured, non-retrying Figma write with one target and a
decreasing deadline. Neither Adapter owns source resolution, Enterprise API
selection, Plugin code, recovery or output formatting.

The Plugin resolves an id, exact name or unique partial name against bounded
local Collections. A query absent from that local set is treated as an explicit
published Collection key, preserving the established library workflow without
silently choosing local ambiguity. Local source Collection Facts validate
before creation.

The returned Extended Variable Collection is journaled immediately. A fresh
local catalog must contain exactly that new id, and guarded postconditions
validate its name, extension identity, parent/root Collection ids, inherited
mode `parentModeId` topology and inherited Variable membership. Guarded failure
removes the exact created Collection and proves its absence where possible;
failed removal or cleanup verification reports one possible residue.

Successful stdout retains the established Collection-shaped JSON, including
native inherited `parentModeId` fields. Parent/root ids are validated in the
internal result but are not added to compatibility output. A complete bounded
Extended Collection read, including override facts, belongs to FID-16 rather
than weakening base Collection Facts with ad hoc optional fields.
