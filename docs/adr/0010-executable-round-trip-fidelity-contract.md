# Classify core fidelity through one executable contract

Core Figma fact families are classified once in a versioned Round-trip Fidelity Contract that covers both directions plus verification. Design Capture, agent-facing projections, Semantic Render Plans and command-specific writers remain their own implementations, but CI rejects an unclassified core fact and write support never implies reverse fidelity; this prevents workflow prose or a one-sided feature test from becoming the source of truth.
