# Own Variable Collection metadata update

`col update` uses one closed Collection Metadata Update Command Application
from Commander and `figma_run`. Its authentic Command Plan is a
confirmation-configured, non-retrying Figma write with one target and
decreasing deadline. Neither Adapter owns Plugin code, field rollback or output
formatting.

The request requires at least one explicit bounded name or
publishing-visibility field before readiness. Names retain the legacy trimmed
form and must contain visible content; visibility accepts only boolean intent.
Collection resolution retains id, exact-name and unique partial-name utility,
while ambiguity fails before mutation.

The Plugin validates complete Collection Facts before the first assignment and
snapshots every requested prior field. Assignments run in deterministic order,
followed by full Facts validation and exact requested-field postconditions. A
guarded failure restores every requested field independently and verifies the
restored value; one failed restoration cannot prevent the other field from
restoring. Restore failure returns the exact failed field names and one bounded
Collection residue identity. No dispatched update retries.

The generated Collection mutation runtime is reusable by later mode mutation
Applications. Successful output retains the established complete Collection
Facts JSON. Mode changes, Collection deletion and extension remain separate
Commands.
