# Own Variable metadata update

`var update` uses one closed Variable Metadata Update Command Application from
Commander and `figma_run`. Its authentic Command Plan is a
confirmation-configured, non-retrying Figma write with one target and decreasing
deadline. Neither Adapter owns Plugin code, field rollback or output formatting.

The request requires at least one explicit bounded name, description,
publishing-visibility or scopes field before readiness. Names retain the legacy
trimmed form, descriptions preserve literal and empty text, visibility accepts
only boolean intent, and scopes accept only the official Figma scope vocabulary.
Variable resolution retains id, exact-name, path-tail and unique partial-name
utility; every ambiguity fails before mutation.

The Plugin validates complete Variable Facts before the first assignment and
snapshots every requested prior field. Assignments run in one deterministic
order, followed by full Facts validation and exact requested-field
postconditions. A guarded failure restores every requested field independently
and verifies the restored value; one failed restoration cannot prevent later
fields from restoring. Restore failure returns the exact failed field names and
one bounded Variable residue identity. No dispatched update retries.

The Application reuses the canonical generated Variable mutation runtime.
Successful output retains the established complete Variable Facts JSON. Mode
values, code syntax, Collection metadata and token import remain separate
Commands.
