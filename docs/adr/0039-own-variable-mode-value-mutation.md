# Own Variable mode value mutation

`var set-value` uses one closed Variable Set Value Command Application from
Commander and `figma_run`. Its authentic Command Plan is a
confirmation-configured, non-retrying Figma write with one target and decreasing
deadline. Neither Adapter owns Plugin code, rollback or output formatting.

The request validates bounded Variable, Collection, mode, literal and alias
payloads before readiness and requires exactly one of a literal or alias.
Canonical argv places payload after `--`. Existing id, exact-name, path-tail and
unique partial-name utility remains available, while every ambiguity fails
before the setter. All six official Variable types, named Easing values, JSON
MotionEasing values and type-compatible Variable Aliases remain supported.

The Plugin snapshots whether the selected mode already had a value and its
prior value before calling `setValueForMode()` once. It then projects and bounds
complete Variable Facts, including the resulting mode value. A guarded failure
restores an existing prior value with the same setter. Figma's current Plugin
API exposes no operation to delete one mode value, so a failure after writing a
previously empty mode returns explicit `partial-residue` evidence with
`no-reversal-api`. A failed restoration returns the same evidence with
`restore-failed`. Such dispatched failures are never retried.

Successful output preserves the established JSON object containing `variable`,
`mode` and `value`. Variable metadata updates, Collection mode management,
batch token import and Variable creation remain separate Commands.
