# Public documentation

This directory contains durable documentation that is useful to users,
contributors, and security reviewers:

- [`adr/`](adr/) records accepted architectural decisions.
- [`figma-plugin-api-coverage.md`](figma-plugin-api-coverage.md) describes the
  supported public Figma Plugin API surface and its boundaries.
- [`css-figma-semantic-matrix.md`](css-figma-semantic-matrix.md) documents
  Code-to-Figma conversion fidelity.
- [`slides-roadmap.md`](slides-roadmap.md) separates supported Slides work from
  current public-API limitations.
- [`releasing.md`](releasing.md) documents the release and provenance process.

Maintainer backlogs, experiments, completed plans, and detailed live-acceptance
records are intentionally kept in the ignored `docs-local/` workspace. They
may contain temporary project context and are not part of the published source
or npm package.
