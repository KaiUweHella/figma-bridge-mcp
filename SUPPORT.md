# Support

figma-bridge-mcp is a single-maintainer open-source project. Support is best
effort: there are no guaranteed response or resolution times.

## Where to ask

- Reproducible defects: open a GitHub issue with the bug-report template.
- Product ideas: open a GitHub issue with the feature-request template and
  describe the workflow, not only the desired command name.
- Usage questions: use GitHub Discussions when enabled; otherwise open an
  issue and mark it as a question.
- Security vulnerabilities: follow [SECURITY.md](SECURITY.md) and use a private
  GitHub security advisory. Never post credentials or exploit details publicly.

Before reporting a bridge problem, include the operating system, Node version,
Figma editor (`figma`, `figjam`, or `slides`), the command you ran, and the
relevant redacted audit-log lines. Do not attach plugin access keys, daemon
tokens, personal access tokens, or private document content.

Pull requests are welcome. [CONTRIBUTING.md](CONTRIBUTING.md) explains the
security and architecture boundaries that changes must preserve.
